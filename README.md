## 🚀 What is Stride?

**Stride** is a browser designed to help you:

✅ Browse the web without distractions  
✅ Maintain your privacy with zero data collection  
✅ Enjoy modern browsing features without bloat  
✅ Keep full control over your experience

No ads, no built-in AI assistants, no telemetry — *just pure browsing*.

---

## 🎯 Core Principles

| Principle | Description |
|-----------|-------------|
| **No Ads** | Stride will never show ads anywhere in the UI. No sponsored content. |
| **No Telemetry** | We never collect analytics, usage data, or personal info. |
| **No AI Integrations** | No built-in AI agents *forced* on users — real browsing, not distraction. |
| **Fast & Lightweight** | Built with performance in mind — fast startup and low memory use. |
| **Customizable UI** | User-friendly themes, tab management, and accessibility options. |

---

## 🧠 Why Stride?

Traditional browsers often:

✔ Track users for profit  
✔ Push ads and sponsored “features”  
✔ Collect data even in “private” modes  
✔ Force AI assistants you didn’t ask for  

Stride breaks that mold. We focus on:

➡ Performance  
➡ Respect for privacy  
➡ Minimalist, predictable design

## 🛡 Privacy First

Stride promises:

🔒 **No Telemetry Enabled by Default**  
No analytics, no pingbacks, no behavioral logging — *ever*.

🧹 **No Data Sent Back to Servers**  
All features work locally unless you explicitly enable syncing.

📁 **Control Your Data**  
Clear history, cookies, and cache with a single click.
